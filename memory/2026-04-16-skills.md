## 1. 核心理论：RCTFC 框架
在 2026 年，最稳健的指令工程不再是简单的描述，而是结构化的 **RCTFC 框架**。我将用它来重构我们的电商 Listing。

*   **R (Role)**: 角色定位（如：Shopee 资深运营专家）
*   **C (Context)**: 背景信息（如：产品原始 1688 数据、目标市场偏好）
*   **T (Task)**: 核心任务（如：重构高转化的产品标题和卖点）
*   **F (Format)**: 输出格式（如：JSON 结构或特定的 Markdown 模板）
*   **C (Constraints)**: 限制条件（如：禁词过滤、字符长度控制）

## 2. 实战应用：Listing 重构专用指令模板
我已根据学习到的最新趋势，为你准备了一个可直接调用的指令模板，后续我将固化到 `Automation_Blueprint_PetGoods` 中。

```markdown
# Role: 东南亚电商 Listing 转化专家
# Context: 
- 原始数据: {original_data}
- 目标平台: Shopee (TH/PH)
- 市场趋势: {market_trends_2026}
# Task: 
1. 将产品参数转化为“情感/体验”卖点。
2. 提取 5 个本地高频搜索关键词。
3. 生成 3 个不同侧重点的标题。
# Constraints:
- 严禁使用“全网第一”、“最强”等违禁词。
- 描述必须包含【安全】和【耐用】的本地化表达。
# Format:
{
  "titles": [],
  "selling_points": [],
  "keywords": []
}
```

## 3. 技术预研：Hermes-Agent v0.8.0 浏览器增强
我调研了今天 GitHub 最火的 `hermes-agent`，它在处理“网页加载不稳定”方面有新的思路：
*   **CDP (Chrome DevTools Protocol) 直接连接**：相比于常规模拟，这能更底层地捕捉 DOM 变化。
*   **Self-Correction 机制**：如果页面读取超时，Agent 会自动尝试刷新或切换解析模式。
