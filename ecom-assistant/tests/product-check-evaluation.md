# Test: Product Check Evaluation

## Purpose
Validate whether product checks can reliably identify obvious listing and maintenance issues.

## Status
not started

## Goal
Test whether the assistant can consistently identify:
- weak / unclear titles
- missing attributes
- SKU structure issues
- low / zero inventory risks
- price anomalies
- abnormal product states

## Evaluation criteria
- issue-detection usefulness
- false positive rate
- clarity of suggested actions
- ability to prioritize obvious risks

## Expected output
- usable / partially usable / not usable
- best-performing check types
- weak check types
- what requires human review
