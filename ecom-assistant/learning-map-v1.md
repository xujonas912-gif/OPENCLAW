# 电商能力学习地图 v1

## 目标

把“小苹果”逐步训练成一个能够服务老板的本地化电商 agent：
- 先能看懂电商
- 再能辅助做决策
- 再能参与执行
- 最终形成可持续迭代的自主化能力

当前阶段重点不是直接运营店铺，而是先打好知识、分析、框架和 agent 化基础。

---

## 学习总原则

1. **先框架，后细节**：先建立电商全局认知，再钻具体平台和战术。
2. **先读后做**：先形成结构化理解，再沉淀 SOP、模板、评分标准。
3. **先分析后执行**：优先学习读数据、比平台、看竞品，不急于对外动作。
4. **先可解释，后自动化**：所有判断都尽量能说明为什么，避免黑箱决策。
5. **持续复盘**：把学到的内容写回知识库、记忆和工作流，形成长期能力。

---

## 学习阶段路线

### 第一阶段：建立基础认知
目标：知道电商生意是怎么运转的。

需要掌握：
- 电商业务基本链路：流量 → 点击 → 转化 → 复购
- 常见平台类型与差异：内容电商 / 搜索电商 / 货架电商 / 独立站
- 店铺生命周期：起店、测款、放量、稳定运营
- 基础角色分工：选品、运营、客服、投放、供应链、数据分析
- 常见核心指标：曝光、点击率、转化率、客单价、退款率、ROI

学习产出：
- 电商全局框架说明
- 常见术语表
- 基础指标解释表

优先级：P0

---

### 第二阶段：选品与竞品分析
目标：具备发现机会和判断风险的能力。

需要掌握：
- 什么是好品
- 需求判断方法
- 竞品调研方法
- 价格带分析
- 利润空间与成本意识
- 评论、卖点、主图、详情页的拆解方法
- 判断“能不能做”和“值不值得做”

学习产出：
- 竞品分析模板
- 选品评分卡
- 商品机会评估框架

优先级：P0

---

### 第三阶段：跨平台理解与比对
目标：形成老板需要的“多平台比对 agent”基础。

需要掌握：
- 淘宝 / 拼多多 / 抖音 / 小红书 / 京东 / Shopify 等平台的核心差异
- 不同平台的流量逻辑
- 不同平台的用户心智
- 不同平台的数据口径差异
- 同商品跨平台价格、销量、评价、内容风格差异
- 如何把不同平台字段做标准化映射

学习产出：
- 平台差异对照表
- 跨平台商品结构化字段表
- 平台对比报告模板

优先级：P0

---

### 第四阶段：内容与转化能力
目标：会判断什么样的商品表达更容易卖。

需要掌握：
- 标题结构
- 主图卖点表达
- 详情页逻辑
- 用户常见顾虑
- 商品文案的说服路径
- 客服话术的成交逻辑

学习产出：
- 标题模板
- 卖点提炼模板
- 详情页结构模板
- 客服回复模板

优先级：P1

---

### 第五阶段：运营与数据分析
目标：能看懂一个店/一个商品为什么表现好或差。

需要掌握：
- 电商日报/周报怎么读
- 流量异常分析
- 转化率分析
- 客诉、退款、差评的影响
- 活动与自然流量的区别
- 广告与自然运营的配合关系

学习产出：
- 运营日报模板
- 异常分析框架
- 指标诊断 SOP

优先级：P1

---

### 第六阶段：供应链与履约
目标：理解电商不是只看页面，还要看供给能力。

需要掌握：
- 货源与供应链基础
- 库存与周转
- 发货时效
- 售后风险
- 低价竞争与利润风险
- 履约能力对评分和复购的影响

学习产出：
- 供应链风险清单
- 履约风险判断表

优先级：P2

---

### 第七阶段：自动化与 agent 化
目标：把学到的能力逐步转成可以复用的 agent 工作流。

需要掌握：
- 哪些环节适合自动化
- 哪些环节必须人工确认
- 信息采集工作流
- 竞品对比工作流
- 报告生成工作流
- 决策支持工作流
- 多 agent 分工方式

学习产出：
- agent 角色分工图
- 自动化边界清单
- 可执行工作流草案

优先级：P0

---

## 第一批重点学习模块（立即执行）

当前最值得优先学习的 4 个模块：

1. 电商基础框架
2. 选品与竞品分析
3. 跨平台差异理解
4. agent 化与自动化边界

原因：
- 现在还没有店铺，适合先学通用能力
- 这四项最适合沉淀成长期资产
- 也最接近未来“自主运行电商管理系统”的底层能力

---

## 学习结果如何沉淀

每次学习都尽量落到这几类资产里：

- `knowledge/`：长期稳定知识
- `templates/`：重复可用模板
- `agents/`：agent 职责和工作流
- `memory/`：当天学习记录和重要结论
- `MEMORY.md`：长期目标和关键方法论

原则：
- 零散信息不算能力
- 能复用的结构才算能力
- 能转成模板 / 规则 / SOP / agent 的，优先沉淀

## 未来能力形态

希望最终形成的能力结构：

### 读懂
- 读懂平台
- 读懂商品
- 读懂竞品
- 读懂数据

### 判断
- 判断能不能做

- 判断值不值得做
- 判断风险点在哪

- 输出结论
- 输出对比
- 输出建议
- 输出报告和草稿

### 协同
- 调度不同 agent 分工处理
- 形成稳定工作流
- 在老板授权下逐步提高自动化程度
